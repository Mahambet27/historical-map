# Аварийная карточка Qazaq Heritage Map

## 1. Карта зависла

1. Нажмите `Ctrl+Shift+O`.
2. Выберите Reset to 1465.
3. Если меню не открылось — перезапустите браузер.

## 2. 3D не загрузилась

1. Закройте 3D-панель.
2. Используйте poster.
3. Продолжайте сценарий; 3D не обязательна.

## 3. Интернет пропал

1. Не останавливайте server.
2. Включите SVG fallback.
3. Продолжайте локальный сценарий.

## 4. Mapbox не открылся

1. Откройте operator menu.
2. Включите Force SVG fallback.
3. Не повторяйте сетевой запрос.

## 5. Интерфейс стал медленным

1. Выберите Light.
2. Нажмите Pause.
3. Продолжайте пошагово.

## 6. Service worker показывает старую версию

1. Откройте `/demo?recovery=true`.
2. Нажмите «Восстановить выставочную версию».
3. Подтвердите очистку только cache проекта.

## 7. Браузер закрыл fullscreen

1. Нажмите кнопку «Открыть полный экран».
2. Если её нет — используйте стандартную команду браузера.

## 8. Компьютер перезагрузился

1. Запустите `start-demo.cmd`.
2. Выполните `check-demo.ps1`.
3. Откройте kiosk и проверьте 1465.
