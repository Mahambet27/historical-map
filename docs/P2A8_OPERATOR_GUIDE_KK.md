# Qazaq Heritage Map операторының нұсқаулығы

Нұсқа: 2026.08-rc1. Көрсетілім Docker, Supabase және интернетсіз жұмыс істейді.

## Көрсетілімге бір күн қалғанда

- Ноутбуктерді зарядтап, Windows жаңартуларын уақытша тоқтатыңыз.
- Offline package checksum тексеруін орындаңыз.
- Браузерді, проекторды, ажыратымдылықты және толық экранды тексеріңіз.
- 1465→1511 сценарийін негізгі және резервтік ноутбукте өткізіңіз.

## 30 минут қалғанда

- Компьютерді қайта іске қосыңыз; Docker қажет емес.
- `start-demo.cmd`, кейін `check-demo.ps1` іске қосыңыз.
- `READY`, тіл, 1465 жыл және kiosk режимін тексеріңіз.
- Хабарландыруларды өшіріп, «Мазаламаңыз» режимін қосыңыз.

## Көрсетілім кезінде және кейін

`Ctrl+Shift+O` оператор мәзірін ашады. Reset 1465 жылға қайтарады. Баяу
құрылғыда Light және SVG fallback таңдаңыз. Соңында `stop-demo.ps1` орындап,
жеке деректер болуы мүмкін журналдарды жарияламаңыз.
