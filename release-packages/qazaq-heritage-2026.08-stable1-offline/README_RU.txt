# Руководство оператора Qazaq Heritage Map

Версия: 2026.08-rc1. Локальная демонстрация не требует Docker, Supabase или
доступа в интернет.

## За день до показа

1. Полностью зарядите основной и резервный ноутбуки.
2. Приостановите автоматические обновления Windows на время мероприятия.
3. Обновления проекта и браузера завершите заранее, не в день показа.
4. Распакуйте offline package и выполните `exhibition:integrity`.
5. Подключите проектор, проверьте разрешение, масштаб и полноэкранный режим.
6. Проверьте звук, даже если текущий сценарий его не использует.
7. Запустите `start-demo.cmd`, затем `check-demo.ps1`.
8. Пройдите весь сценарий 1465→1511, источники, маршрут, SVG и 3D poster.
9. Повторите проверку на резервном ноутбуке.

## За 30 минут

1. Перезапустите компьютер.
2. Docker запускать не нужно.
3. Запустите offline package и убедитесь, что status — `READY`.
4. Откройте kiosk, подтвердите fullscreen.
5. Включите Windows «Не беспокоить» и отключите уведомления.
6. Проверьте мышь, клавиатуру и комбинацию `Ctrl+Shift+O`.
7. Выберите нужный язык и quality.
8. Проверьте default 1465 и переход к 1511.

## Во время показа

- Operator menu: `Ctrl+Shift+O` либо удержание верхнего левого угла.
- `Start official story` начинает основной сценарий.
- `Pause` останавливает движение.
- `Reset to 1465` закрывает панели и journey без перезагрузки.
- При медленной работе выберите Light и Force SVG fallback.
- При зависании откройте operator menu; если оно не реагирует, перезапустите
  только браузер. Server останавливайте только через `stop-demo.ps1`.
- `Esc` в kiosk открывает безопасное operator menu.

## После показа

1. Закройте браузер и выполните `stop-demo.ps1`.
2. Сохраните только safe technical summary и результаты checksum/status.
3. Не публикуйте runtime logs, если в них могут быть пользовательские данные.
4. Не копируйте PID, локальные пути или сведения устройства в публичный отчёт.
